# WotRatings

Бібліотека PHP 8.5 готує статистику World of Tanks і розраховує ER, WN6, WN8 та історичні рейтинги. Канонічний опис входів, відповідей, встановлення й доступних методів: [англійський README](../../README.md).

Застосунок завантажує WG-відповіді, каталог техніки й expected-таблицю. `PlayerDataPreparer` приймає записи одного гравця через `setData()` або декодовані відповіді через `setApiResponses()`. Підготовлені асоціативні масиви можна змінювати й передавати у методи `WotRatings` через `...`. `fromApiResponses()` створює новий preparer і викликає setter. Наявні методи збережено.

## Необов'язковий логер

```php
/** @var \Psr\Log\LoggerInterface $logger Логер зовнішнього застосунку. */
$preparer = new \Edrard\WotRatings\PlayerDataPreparer($catalogue, logger: $logger);
```

`logger` — останній необов'язковий аргумент конструктора та фабрики. Без логера або з null використовується `NullLogger`, результати працюють без виводу. Чисті калькулятори логера не потребують.

Переданий `NullLogger`, включно з його підкласами, явно вимикає діагностику. Для власного логера із записом повідомлень реалізуйте `LoggerInterface` або успадкуйте `Psr\Log\AbstractLogger`.

Після завантаження даних або заміни full-статистики може бути один підсумок проблем: warning для розбіжностей боїв або некоректних даних, debug для відсутніх даних режимів. Лог містить лише кількість режимів із розбіжністю та недоступних/некоректних пар рейтинг–режим. Повністю готові дані, повторні перевірки й розрахунки не логуються. Сирі записи, ID гравців, нікнейми, токени й expected-таблиця не потрапляють у контекст.

Виняток або Error від логера не змінює статус, звіт, підготовлені аргументи або початковий виняток бібліотеки. Доставка журналу не повторюється; сховище, фільтри й утримання визначає застосунок. PSR-3 синхронний: для доставки без очікування використовуйте логер із власною чергою.

## Перевірки

Після `composer install`: `composer test`, `composer analyse`, `composer format:check`. Приклад використання: `php examples/player-ratings.php`. Бібліотека не виконує мережевих запитів.
